# ACF Evaluation

Generated by `tests/lune/evaluate.luau full` (Lune 0.10.5). Seeds 1–10; 30 honest players
and one of each cheat per seed; 10 simulated minutes per seed; cheats start at 60 s.
Enforcement runs in shadow mode so cheaters stay in the server to be measured; the
"would do" column is what enforcement decided.

## Memory and stability soak
